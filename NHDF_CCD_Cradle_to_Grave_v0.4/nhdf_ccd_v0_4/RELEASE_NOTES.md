# Release notes - NHDF-CCD v0.4.0

Date: 1 September 2026

## Architectural turn

This release centers the NHDF/PCKF research program on **Continuous Collision Detection**. The original local-zero-set, log-polar, parity, bounded-routing, forward-time, analytic-sweep, projection, and feedback vocabulary is retained only where it has a typed role. Collision decisions are controlled by conservative geometry, motion bounds, exact or bracketed time-of-impact solvers, and explicit failure states.

## Executable evidence in this archive

- 22 Python tests.
- One C++17 smoke test.
- Exact linear sphere-sphere, sphere-plane, and translating axis-aligned-box CCD.
- Conservative advancement for supported separation oracles and declared SDF contracts.
- Conservative swept-AABB broad phase.
- Four deterministic reference certificates.
- A fixed-seed 5,000-query sphere-sphere differential benchmark.
- Schemas, status semantics, risk register, traceability matrix, GPU port plan, integration controls, operations, retirement, and separated adapter documents.

The current executable claim is deliberately narrow. It does not establish production-grade rigid-convex, triangle-mesh, deformable, self-collision, simultaneous-contact, response, GPU, optical, quantum, chemical, biological, medical, fabrication, or cosmological execution.
