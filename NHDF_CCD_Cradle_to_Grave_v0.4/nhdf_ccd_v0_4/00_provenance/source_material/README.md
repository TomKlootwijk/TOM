# Supplied source material

This directory contains the three directly mounted source PDFs used to reconstruct the development sequence:

- `S1_original_operator_chain.pdf` - initial 30-page prompt chain.
- `S2_NHDF_Formal_Specification_v0.1.pdf` - first non-degenerate formal specification.
- `S3_commute_design_transcript.pdf` - 40-page commute/design extension containing the initial CCD claim and the log-polar Jacobian correction.

The fourth source, **S4 - spherical-Cartesian / whole-substrate extension**, was supplied as a separate conversation attachment. Its claims and domains are registered in `../SOURCE_REGISTER.md` and mapped throughout `10_domain_adapters/`; the raw attachment was not available as a mounted byte stream when this archive was finalized, so it is not silently reconstructed or substituted.

These source files contain exploratory material and may include personal or location context. They are evidence of the design lineage, not proof of technical validity. Do not use personal civil metadata from them as cryptographic material.
