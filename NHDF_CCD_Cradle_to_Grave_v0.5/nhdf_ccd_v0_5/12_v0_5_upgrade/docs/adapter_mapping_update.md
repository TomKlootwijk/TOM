# Separate adapter mapping after the CCD turn

The v0.5 core is literal engine CCD. Other NHDF materials remain adapters with independent evidence burdens:

| Adapter | Reusable CCD artifact | Required independent evidence | Current boundary |
|---|---|---|---|
| Sensors / metrology | timestamped state, residual, certificate | calibration, uncertainty, traceability | interface hypothesis |
| SAR / wave sensing | swept support and event intervals | wave equation, sensor model, field trials | unvalidated adapter |
| GPU / edge AI | bounded queues, deterministic replay | kernel equivalence, quality and thermal tests | CPU reference only |
| Optical / photonic | operator pipeline and closed-loop telemetry | measured transfer function, drift and energy | restricted experiment proposal |
| Quantum / Cross-Kerr | parity/event semantics | Hamiltonian, preparation, noise, readout | hypothesis only |
| Chemical networks | event graph and feedback | stoichiometry, kinetics, thermodynamics | controller adapter |
| Biological / medical | time-indexed observations and residuals | mechanism, preclinical and clinical evidence | non-therapeutic model only |
| Fabrication | geometry/certificate interchange | process window, yield, metrology | manufacturing adapter |
| Cosmology | boundary notation | explicit dual theories and observable map | no physical duality established |

No adapter inherits validity from the CCD tests. A shared data shape is not a shared constitutive law.
