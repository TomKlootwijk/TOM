# NHDF-CCD Cradle-to-Grave v0.5

This is the cumulative research release centered on literal continuous collision detection for computer graphics and physics engines.

The preserved v0.4 tree contains the primitive/reference foundation and original lifecycle dossier. The new `12_v0_5_upgrade/` gate adds linearly moving vertex–face and edge–edge CCD, rigid-motion speed envelopes, deterministic simultaneous-event grouping, a restricted frictionless response example, and a reproducible adapter for a licensed public adversarial query corpus. `13_baseline_release/` preserves the prior v0.4 PDF and ZIP byte-for-byte.

## Primary deliverables

- `NHDF_CCD_Cradle_to_Grave_v0.5.pdf` — cumulative dossier distributed beside this project tree.
- `12_v0_5_upgrade/report/main.pdf` — v0.5 addendum before the v0.4 baseline is appended.
- `12_v0_5_upgrade/src/` — executable Python reference.
- `12_v0_5_upgrade/cpp/` — compiled C++17 bounds/events/impulse translation.
- `12_v0_5_upgrade/gpu/` — non-conformant CUDA coefficient-stage skeleton.
- `12_v0_5_upgrade/validation/` — tests, raw records, figures, environment, logs, and PDF checks.
- `12_v0_5_upgrade/corpus/vendor/` — two third-party Sample-Queries files plus upstream README and MIT license.

## Scientific boundary

The feature solver is double-precision reference code. It is not exact arithmetic and is not certified for production safety. Rotating triangle meshes, complete deformable self-collision, GPU equivalence, and a full rigid-body response solver remain future gates. Non-CCD optical, quantum, chemical, biological, medical, fabrication, and cosmological materials remain independent adapters; they gain no validity merely because the CCD tests execute.

```bash
./tools/run_all.sh
```
