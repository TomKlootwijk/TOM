# Normative no-failsafe core

TOMAGI 1.0 follows the request to remove the corrective and protective layers proposed in earlier drafts.

The following are **not** normative runtime operators:

- jitter guard intervals and event-margin rejection;
- Hamming/ECC upgrades of the one-bit operator;
- damping, restoration or boundary-contraction forces;
- confidence floors or probabilistic thresholds;
- safe mode, watchdog routing or emergency stop policy;
- dynamic allocation reserve policy or memory safety ring;
- claims-ledger kill criteria used to reject a source motif.

The one-bit value is retained literally as parity-conditioned route and signed perturbation. `SDF0` is retained literally as zero on every defined LUT address. Structural file validity - fixed record sizes, resolvable IDs, unique keys and declared successors - is part of the language grammar, not a corrective control layer.
