TOM.TRANSITION & state patch & state x cell -> state & Execute exactly one opcode, normalize periodic fields, select successor, and update lineage. \\
TOM.PROJECT & symbolic projection & state x tag -> tag & Emit a side-view pyramid, circle, sphere, action, class, or other downstream token without making projection the substrate. \\
TOM.EMIT & deterministic output & state x payload -> state & Set the output token and emitted bit; optional halt is a program semantic, not a safety mode. \\
