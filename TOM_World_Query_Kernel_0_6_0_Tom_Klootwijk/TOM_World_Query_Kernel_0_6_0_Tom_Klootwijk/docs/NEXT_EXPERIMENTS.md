# Next experiments after WQK 0.6

## 1. Interval-valued observation authority

Define exact rational observation intervals and a finite registry of declared measurement/noise models. Keep the model, scoring rule, calibration set, and coverage test as static content-addressed formal authority.

## 2. Calibration and coverage certificates

For each finite noise family, generate exact calibration records, held-out coverage results, and failure examples. A confidence value must remain evidence inspected by explicit support, compatibility, guard, decision, and promotion records; it must not alter TOMAGI opcodes invisibly.

## 3. Robust finite candidate scoring

Add a bounded exact scoring profile for interval residuals. Either provide a declared total order or emit an ambiguity record when scores are equal or incomparable. Test label-preserving and label-changing validation/holdout mutations.

## 4. Distribution-shift records

Create out-of-profile observations that satisfy neither the declared calibration assumptions nor the accepted support. The learner should produce an explicit shift/rejection record rather than extrapolate silently.

## 5. Noisy supersession and regression impact

Re-evaluate every pinned promoted definition under the same declared error model. Reject promotions with incomplete calibration evidence or unacceptable regression impact.

## 6. Memory 0.1 design benchmark

Define semantic, episodic, procedural, and working-memory records with retrieval certificates. Compare exhaustive and indexed retrieval while preserving contradiction, provenance, supersession, and temporal context.

## 7. Planner 0.1 controlled domain

Represent goals, preconditions, effects, costs, permissions, candidate plans, simulations, execution observations, and replanning certificates. Keep tool/action execution outside authority until an explicit capability gate approves it.

## 8. Controlled-language observation adapter

Translate a synthetic language into non-authoritative observation records with exact source spans and uncertainty. Measure extraction accuracy separately from learner acceptance and promotion.
